# StopTimesList

Shows the next buses at a stop, one row per bus: a line badge, the
destination (headsign), the delay relative to schedule, the arrival time, and
a **Live** / **Schedule** pill so you can tell a realtime prediction from a
timetable time at a glance.

This is the same component the dashboard renders — the showcase uses the
single shared implementation, so what you see here matches the app.

## Props

| Prop    | Type        | Required | Description                                                                                    |
| ------- | ----------- | -------- | ---------------------------------------------------------------------------------------------- |
| `times` | `Passing[]` | yes      | The bus rows to render. When empty, the list shows the "No more buses scheduled today." state. |

A `Passing` row carries the line short name, headsign, and scheduled arrival;
optionally a live source. When `source` is `'live'` with a `predictedAt`, the
row shows the predicted time and a **Live** pill; otherwise it shows the
scheduled time and a **Schedule** pill.

## States

### Mixed

Rows with live predictions sit next to schedule-only rows; each row is
labelled independently.

<Canvas of={StopTimesListStories.Mixed} />

### Schedule only

When no realtime data is available for a stop, every row falls back to the
timetable and is marked **Schedule**.

<Canvas of={StopTimesListStories.ScheduleOnly} />

### Empty

When there are no more buses scheduled today, the list shows its empty state
instead of a list.
